# 춘식이의 일정 - Vanilla JS Todo App

## 프로젝트 소개
HTML / CSS / Vanilla JS만을 사용해서 만든 Todo 앱이에요.
AI 도구를 활용한 개발 워크플로우를 직접 경험하고, 생성된 코드를 이해하고 수정하는 것에 집중했어요.

## 사용 기술
- HTML
- CSS
- Vanilla JS
- Web Storage API (localStorage)

## 파일 구조
todo-vanilla/
├── index.html
├── style.css
├── app.js
└── README.md

## 구현 기능

### 기본 미션
- Todo CRUD (추가 / 수정 / 삭제 / 완료 처리)
- 빈 입력값 제출 시 에러 메시지 표시
- 상태별 필터링 (전체보기 / 해야할 일 / 달성한 것)
- Todo 일간 뷰 (날짜별 Todo 관리)
- 로컬스토리지 연동 (새로고침 후에도 데이터 유지)

### 도전 미션
- 주간 뷰 (날짜별 Todo 개수 표시)

### 추가 기능
- 월간 뷰 (달력 형태, 날짜별 Todo 개수 표시)
- 주간 / 월간 뷰 전환 기능
- 날짜별 소감 한마디 작성 / 수정 / 삭제 (말풍선 형태)

## 직접 커스텀한 부분
- 카카오 춘식이 캐릭터 이미지를 활용한 디자인으로 커스텀
- 탭마다 다른 GIF 이미지 표시
- 토요일 파란색, 일요일 빨간색으로 요일 색상 구분
- 오늘 날짜일 때만 배경색이 노란색으로 바뀌도록 수정
- 말풍선 색상을 연한 회색으로 변경

## 어려웠던 점
- 외부 이미지 링크 사용 시 이미지가 깨지는 문제 → 외부 서버에서 직접 링크 접근을 막아놓은 경우가 있어서 발생한 문제였고, 이를 고려하여 이미지 링크를 교체해서 해결했어요.
- 코드의 전체적인 흐름을 이해하지 못한 채 수정하다 보니 원하는 방향으로 안 되는 부분이 많았어요.

## 과제 회고
- 잘한 점: AI가 생성한 코드를 그대로 쓰지 않고, 어느 부분을 수정해야 하는지 계속 물어보면서 직접 수정했어요.
- 아쉬운 점: 코드의 전체적인 흐름을 이해하지 못한 채 수정해서 원하는 방향으로 안 되는 부분이 많았어요.
- 다음에 시도해볼 것: 프론트엔드를 더 깊이 이해하고 AI 없이도 처음부터 직접 계획하고 제작해보고 싶어요!
