## AI 활용 내역

### Todo CRUD 구현하기

- AI 활용 내용 : 아래 프롬프트로 입력창, 추가 버튼, Todo 목록이 포함된 HTML 레이아웃과 수정 / 완료 / 삭제 기능이 달린 기본 CRUD 코드를 받았어요.

```
Todo 앱의 HTML 레이아웃과 기본 CRUD 기능을 만들어줘.

- 텍스트 입력창과 추가 버튼으로 Todo를 생성할 수 있어야 해
- 생성된 Todo는 목록으로 표시되고, 각 항목마다 수정 / 완료 / 삭제 버튼이 있어야 해
- 입력값이 비어있으면 Todo가 생성되지 않고 안내 메시지를 표시해줘
- 완료된 Todo는 텍스트에 취소선이 표시되어야 해
```

- 직접 수정한 부분 : 깔끔한 느낌의 흰색 스타일과 카카오 춘식이 캐릭터 이미지를 활용한 디자인으로 직접 커스텀했어요. 또한 춘식이 이미지 크기, 제목 폰트 크기, 간격 등을 직접 조정했어요.
- 수정 이유 : 기본 제공된 보라색 스타일보다 카카오 캐릭터인 춘식이의 느낌에 맞는 개성 있는 디자인으로 만들고 싶었어요.

### 상태별 필터링 구현하기

- AI 활용 내용 : 전체보기 / 해야할 일 / 달성한 것 탭을 구현했고, 각 탭마다 빈 상태일 때 다른 GIF 이미지가 표시되도록 요청했어요.
- 직접 수정한 부분 : 각 탭의 빈 상태에 표시될 GIF 이미지와 메시지를 직접 선택하고 교체했어요.
- 수정 이유 : 처음에는 모든 탭에 같은 GIF가 표시됐는데, 탭마다 다른 GIF를 보여주고 싶어서 app.js의 renderTodoList 함수를 수정했어요.

### 달력 스타일 커스텀하기

- AI 활용 내용 : 요일마다 해당 날짜의 할 일 개수가 표시되는 주간/월간 달력을 구현받았어요.
- 직접 수정한 부분 : 토요일은 파란색, 일요일은 빨간색으로 색상을 변경했어요. 또한 선택된 날짜 표시 칸에서 오늘 날짜일 때만 배경색이 노란색으로 바뀌도록 수정했어요.
- 수정 이유 : 요일을 한눈에 구별하기 어렵고, 오늘 날짜도 달력에서 바로 알아보기 힘들어서
  직접 style.css에서 해당 클래스를 찾아 색상을 수정했어요.

### 날짜별 소감 한마디

- AI 활용 내용 : 춘식이 이미지 옆 말풍선 형태로 날짜별 소감을 작성 / 수정 / 삭제할 수 있는 기능을 구현했어요. 날짜를 이동하면 해당 날짜의 소감이 표시되고 로컬스토리지에 저장돼요.
- 직접 수정한 부분 : 말풍선 색상을 카카오 노란색(#fae100)에서 연한 회색(#f0f0f0)으로 변경했어요. 춘식이 사진 크기(140px)와 제목 폰트 크기(40px), 간격도 직접 조정했어요.
- 수정 이유 : 노란 말풍선이 전체적인 흰색 톤과 어울리지 않아 보여서 더 자연스러운 색으로 바꿨어요. 말풍선과 제목의 사이 간격이 너무 좁아서 조절했어요. 제목이 잘 보이지 않아서 크기를 조절했어요.
